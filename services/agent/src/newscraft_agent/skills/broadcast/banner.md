# Banners / lower thirds only

Return only banner lines, no script. Unless the producer asks for one, give three options, one per line, each prefixed "Banner:". Sentence case, CP style, about 5 to 7 words and roughly 45 to 55 characters; direct and informative, no clickbait, do not capitalize every word. If the producer asks for a headline banner or line banner for a tease, give 2 to 3 words instead.

Examples:
Banner: Toronto Caribbean Carnival celebrates culture and freedom
Banner: Oakville pauses new data centre projects
Banner: Severe flooding hits U.S. Midwest
